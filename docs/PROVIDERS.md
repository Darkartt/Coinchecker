# Provider coverage and production use

Checked 2026-10-03. The application supports Ethereum (1) and Base (8453). Status is recorded separately for every source: `ok`, `partial`, `unavailable`, `unsupported`, or `not_configured`. “Complete source response” does not mean complete security analysis. No result certifies safety.

Provider responses are untrusted data. Fixed provider hosts, no redirects, bounded response size, URL/address checks and escaped text protect the application. Credentials are never saved in report evidence. Source payload digests support inspection; they are not external signatures or independent attestations.

## Quotas and terms

Redis pacing is shared between API replicas (CoinGecko approximately one request every 2.2 seconds, GoPlus 550 ms, Etherscan 400 ms, other HTTP providers 150 ms). This is conservative request spacing, not a guarantee against account-specific quotas. Queues are bounded; 429 gets one retry; reports show failures. Monitor frequency and the 50-token maximum must be sized to your actual plans and user count.

Honeypot.is explicitly restricts third-party availability of API functionality and development of competing products. The production adapter defaults to disabled until the operator has cleared permission; set `HONEYPOT_PRODUCTION_PERMISSION=true` only then. This is a concrete release dependency, not an assertion that the general public terms authorize this product.

Before public/commercial distribution, the operator must confirm the selected plans permit the intended use, redistribution/storage, attribution and expected traffic. Account-specific approvals cannot be established by reading public API docs. Review [Honeypot terms](https://docs.honeypot.is/terms), [DEX Screener API terms](https://docs.dexscreener.com/api/api-terms-and-conditions), [CoinGecko API terms](https://www.coingecko.com/en/api_terms), and the GoPlus/Etherscan terms supplied with your account. Do not advertise universal exchange coverage, detection accuracy, or lifetime history.

## Live observations

Public Ethereum/Base USDC scans successfully returned GoPlus, DEX Screener, CoinGecko metadata/price history and chain state. Base's highest indexed-liquidity route returned an Aerodrome Honeypot response outside documented coverage; that raw result is retained without using its misleading 100% tax/honeypot conclusion. Ethereum returned a supported Uniswap simulation. Public Ethereum log queries were partial. These are operational checks, not token endorsements or a historical detection benchmark.

Authenticated Etherscan and CoinGecko plan coverage remain unverified until the owner configures keys. Adapter contract tests exercise authenticated request construction and response behavior using labelled fixtures.
