# Coinchecker

Understand a token before interacting: its risks, recorded history, and the evidence behind each finding.

Coinchecker is a read-only Chrome extension for Ethereum and Base with an integrated backend. It provides evidence-linked token risk findings, market and pool context, contract links, recorded scan comparisons, configurable watches, and change alerts.

The application source and setup instructions are on the [implementation branch](https://github.com/Darkartt/Coinchecker/tree/codex/build-coinchecker).
